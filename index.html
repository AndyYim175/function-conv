How the fraction is built

Any expression containing polynomial terms (like x²) and exponential terms (like 3ˣ) is converted into a single exact fraction.

  • Polynomials are expressed using Pascal triangle rows:
    • row 1 (all ones) → 1/(B‑1)
    • row 2 (1,2,3,…) → B/(B‑1)²
    • row 3 (1,3,6,…) → B²/(B‑1)³
    • … and so on (row r → Br‑1/(B‑1)r)
  • Exponentials nˣ contribute n/(B‑n).

All terms are combined with their integer coefficients and simplified to an exact fraction using unlimited‑precision arithmetic (BigInt).

For more details, see our research paper.

Note: The parser accepts only integer constants, x, +, -, * (only constant × term), and ^ either as x^k or n^x.
